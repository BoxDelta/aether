# ADR-016: Mobile web over Tailscale as the Android route

**Status:** Accepted\
**Date:** 2026-11-14\
**Owner:** BoxDelta

## Context

A native Android app is a large project before the backend is stable.

## Decision

v1 web UI is responsive and reached from the phone over Tailscale. Native Android app is a Future item.

## Consequences

Phone access early with no extra app. Fewer native features (notifications may be limited).

## Revisit when

Push notifications or offline use become essential.
